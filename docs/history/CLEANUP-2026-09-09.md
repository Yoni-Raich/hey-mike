# Workspace cleanup — 2026-09-09

This cleanup was performed after the public-documentation build gate passed.
It did not change application source, runtime inputs, device state, or another
worktree.

## Removed from the repository workspace

- Gradle `clean` removed generated output from all 10 modules. The module build
  directories used about 4.7 GB before cleanup.
- Project-local `.gradle` and `.kotlin` caches were moved out of the repository.
- The ignored `artifacts/` tree, temporary logs, and remote attachments were
  moved out of the repository.
- The unused `android-agent-ui.avd` directory was moved out after confirming
  that no emulator process or local AVD registration referred to it. It used
  about 8.6 GB.
- Old APK inspection directories, alias APKs, logs, and screenshots under
  `.codex-work/` were moved out. Only the current runtime cache remains there.

## Artifact verification

Before moving `artifacts/`, 17 local APKs were SHA-256 matched to their GitHub
Release assets. Ten additional APKs were local intermediate, aligned, or
experimental builds with no same-name release asset. Nothing in this group was
permanently deleted during this pass.

The moved files are in the sibling directory
`../Android-agent-use-cleanup-quarantine-20260909`. Published artifacts can also
be downloaded again from GitHub Releases. Local-only builds should be reviewed
before the quarantine directory is deleted.

## Preserved

- `local.properties`;
- `research/runtime/` and `.codex-work/runtime/`;
- `.claude/` and every registered worktree;
- every uncommitted file in the protected worktrees;
- the configured Android device and app-private data.

The quarantine directory is not part of the repository and is not committed.
